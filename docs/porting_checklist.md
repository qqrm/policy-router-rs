## Как заполнять

1. Добавьте список C-модулей/функций из исходного проекта в первый столбец.
2. Сопоставьте каждый пункт конкретному Rust-файлу или модулю.
3. Обновляйте статус:
   - **done** — порт завершён, покрыт тестами и поведение эквивалентно.
   - **in_progress** — активная миграция.
   - **blocked** — без C-исходников/спецификаций или есть другие блокеры.
4. Заполните признаки готовности:
   - **Тесты**: перечислить конкретные тесты/проверки (unit/integration/e2e).
   - **Эквивалентность поведения**: ссылка на проверку, спецификацию или список кейсов.
   - **Недостающие функции**: перечень функций, которых ещё нет в Rust.
